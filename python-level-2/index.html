Sorting is different from reversing

sort() changes the list and returns None. sorted() creates a new sorted list. reverse() reverses the current order without sorting.

Compare the three operations

scores = [82, 95, 71]
print(sorted(scores))
print(scores)
scores.reverse()
print(scores)
scores.sort(reverse=True)
print(scores)
Check the output

[71, 95, 82]
[95, 82, 71]

A second name is not a copy

b = a gives the same list another name. a.copy() or a[:] makes a shallow copy. Nested lists inside a shallow copy are still shared.

Compare an alias and a copy

original = [1, 2, 3]
alias = original
copied = original.copy()
alias.append(4)
print(original)
print(copied)
Check the output
[1, 2, 3, 4]
[1, 2, 3]

LESSON 03

range() & repetition

Generate integer sequences and visit a list using its indexes.

range(start, stop, step) includes the start and excludes the stop. The default start is 0 and the default step is 1. A step must not be zero. A range is an immutable sequence, not a list; use list() to display its values.

print(list(range(1, 6)))

LESSON 04

Tuples & immutability

Represent an ordered record whose item references cannot be replaced.

A tuple supports indexing, slicing and loops like a list, but you cannot assign to, add to or delete its individual positions. A single-item tuple needs a comma: (23,). Concatenating tuples creates a new tuple.

Read and rebuild a record

student = (23, "Ada", "2008-03-20")
print(student[2])
print(type((23)).__name__)
print(type((23,)).__name__)
updated = student + ("Macau",)
print(updated)
print(student)
print(tuple(sorted((3, 1, 2))))
Check the output
2008-03-20
int
tuple
(23, 'Ada', '2008-03-20', 'Macau')
(23, 'Ada', '2008-03-20')
(1, 2, 3)

Watch the distinction: student[0] = 24 raises TypeError. A list stored inside a tuple can still change. del student removes the name; it does not delete a position inside the tuple.

A mutable object inside a tuple

record = ("Ada", [90, 80])
record[1].append(95)
print(record)
Check the output
('Ada', [90, 80, 95])

LESSON 05

Dictionaries & key–value pairs

Look up a value by its key instead of a numbered position.

Use braces for key–value pairs: {"name": "Ada"}. Keys are unique and must be hashable; strings and numbers are common choices. A list cannot be a key. Reusing a key replaces its earlier value. key in dictionary checks keys, not values.

Create, read, add, update and delete

prices = {"milk": 18, "eggs": 30}
print(prices["milk"])
prices["bread"] = 12
prices["milk"] = 23
print(prices)
print("eggs" in prices)
del prices["eggs"]
print(prices.get("eggs", "Not found"))
for product, price in prices.items():
    print(product, price)
Check the output
18
{'milk': 23, 'eggs': 30, 'bread': 12}
True
Not found
milk 23
bread 12

Missing key? prices["rice"] raises KeyError if the key is absent. Check membership first or use get(). Use keys(), values() and items() to iterate over keys, values and pairs.

Strings & formatting

Split, join, replace and search text, then format clear messages.

A string is an immutable sequence of characters. It supports indexing, slicing, len(), concatenation with +, repetition with *, and membership with in. Methods such as replace() return a new string.

LESSON 07

Decisions with if

Choose one path using a condition, then test the boundaries.

Use if for a condition, elif for another possibility and else for the remaining case. Python runs only the first matching branch in one chain. Every condition line ends with a colon; indent its body consistently.

Compare with ==, !=, <, <=, > and >=. Combine conditions using and, or and not. = assigns a value; == compares values.

Grade boundaries

score = 80
if score < 0 or score > 100:
    print("Invalid score")
elif score >= 90:
    print("Excellent")
elif score >= 80:
    print("Good")
elif score >= 60:
    print("Pass")
else:
    print("Try again")
Check the output
Good

Nested decisions: divisibility

number = 12
if number % 2 == 0:
    if number % 3 == 0:
        print("Divisible by both 2 and 3")
    else:
        print("Divisible by 2 only")
else:
    if number % 3 == 0:
        print("Divisible by 3 only")
    else:
        print("Divisible by neither")
Check the output
Divisible by both 2 and 3

LESSON 08

for, while, break & continue

Repeat work, update your state and know when the loop stops.

Use for to visit each item in an iterable. Use while to repeat while a condition remains true. A while loop needs a way for its condition to become false or a reachable break.

Accumulate a total

total = 0
for number in range(1, 6):
    total += number
print(total)

counter = 1
total = 0
while counter <= 5:
    total += counter
    counter += 1
print(total)
Check the output
15
15
StatementEffect

continueSkip the rest of this iteration and begin the next one.
Loop elseRun when the loop finishes without a break.

Skip one number, stop at another

for number in range(1, 8):

        continue
    if number == 6:
        break

Review & readiness

Explain your choices, trace unfamiliar code and test your own programs.

Choose a useful data type

TypeExampleUseful for
list["Ada", "Ben"]An ordered collection you can change.
tuple(23, "Ada")An ordered record with fixed item references.
dict{"Ada": 90}Finding values by unique keys.
str"Python"Text, indexing and text operations.
rangerange(1, 6)An immutable integer sequence.
set{1, 2, 3}Unique hashable values; no positional indexing. Mentioned in the source outline.

Common bugs to recognise

  • Using index 1 for the first item, or including the stop of a slice or range.
  • Writing scores = scores.sort() and replacing the list with None.
  • Confusing append with extend, or reverse with descending sort.
  • Trying to change a tuple position or a string character.
  • Using a missing key, or calling index on a value that is absent.
  • Forgetting a colon, changing indentation or failing to update a while-loop counter.
  • Naming variables list, sum, str or dict, which hides useful built-ins.

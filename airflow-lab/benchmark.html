How to interpret these measurements

Same physics, different execution

Both working modes import the exact same D2Q9 JavaScript solver. A Worker moves the computation off the UI thread; it does not automatically make each step faster.

Keep tests comparable

Compare results collected on the same device, with identical grid, object, flow speed and measured steps. Changing resolution can also change the simulated result.

Mind the caveats

Thermal throttling, browser background tabs, device power mode and first-run compilation can affect timings. For better comparisons, run three repeats and compare medians.

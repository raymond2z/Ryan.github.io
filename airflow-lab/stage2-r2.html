How to interpret these measurements

Same physics, different execution

JS + Worker run the same JavaScript D2Q9 code. Rust/WASM is a separate compiled implementation with matching equations, shape masks and warmup. Compare numerical differences as well as speed.

Keep tests comparable

Compare results collected on the same device, with identical grid, object, flow speed and measured steps. Changing resolution can also change the simulated result.

Mind the caveats

Thermal throttling, background tabs and device power mode affect timings. WASM download/compilation is excluded from solver time. Test both engines on the same device and compare three-run medians.

TEACHER SETUP

把實驗紀錄
收進私人試算表。

檔案匯入功能已可使用。Google Sheets 收件需要你先部署以下程式；目前網站尚未連接你的 Google 帳戶。

一次設定

  1. 在 Google Drive 建立私人 Google Sheet，複製網址中 /d/ 和 /edit 之間的試算表 ID。
  2. 開啟 Google Apps Script 建立專案，貼上 collector.gs 接收程式 的完整內容。
  3. 在「專案設定 → 指令碼屬性」加入 SPREADSHEET_ID（上面的 ID）和 CLASS_CODE（自訂本班提交代碼）。代碼是收件門檻，不是學生身分驗證。
  4. 「部署 → 新增部署 → 網頁應用程式」，以你自己執行。存取對象優先選學校網域；依學校政策和學生帳戶設定。授權後取得以 /exec 結尾的網址。
  5. 用學生帳戶測試：從 Derby Lab 下載紀錄，再到收件網址上傳。確認頁面出現收據，試算表的 Receipts 頁出現資料後，再把網址交給全班。

使用方式

學生每次正式實驗先保存在瀏覽器，選定最終方案後下載 JSON，透過你部署的收件頁提交。頁面在伺服器完成寫入後才顯示收據；相同檔案重試不會重複收件。

Receipts 顯示學生代碼、實驗次數、最終方案和理由；Record data 保存完整 JSON 分段。學生也可把原檔交到 Classroom，再由你在教師總覽批次匯入。

試算表僅分享給需要查看的教師。不要將試算表公開；程式不提供讀取全班資料的公開入口。教師匯入頁本身不儲存雲端資料，也不是登入後台。

目前尚未實作背景自動同步。網路失敗時保留下載檔，重新提交；不要把「已在瀏覽器保存」當作「老師已收到」。

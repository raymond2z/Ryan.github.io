TEACHER SETUP

自動收集實驗，
保留學生的思考。

學生端已加入同步、收到確認和重試機制。你需要先在自己的 Google 帳戶部署接收程式，網站才會有可用的收件地址。

一次設定

  1. 開啟 Google Apps Script 建立專案，貼上 collector.gs 接收程式 的完整內容。
  2. 在編輯器選擇並執行 initializeTeacher_，完成 Google 授權。執行記錄會顯示新建的私人試算表網址及班級提交代碼。重複執行會保留原設定。也可沿用舊試算表，在專案設定的指令碼屬性填寫 SPREADSHEET_ID 和 CLASS_CODE。
  3. 「部署 → 新增部署 → 網頁應用程式」，以你自己執行。存取對象依學校帳戶政策設定，優先限制學校網域。取得以 /exec 結尾的網址。更新舊部署時，請編輯部署並選擇新版本。
  4. 在下方產生學生連結。以學生帳戶測試：按 Connect，再記錄一次實驗；確認學生頁顯示 Teacher received，試算表的 Latest students 同時出現該筆資料。

學校登入或瀏覽器封鎖嵌入登入時，自動提交可能無法取得收據；學生頁提供「開啟收件頁」以手動交回下載檔。實際 Google 部署與跨網域傳送尚需完成以上測試。

產生學生連結

教師會看到甚麼？

Latest students：每個學生工作階段的最新實驗次數、最終方案、理由和完整設定。舊版本重試不會覆蓋較新紀錄。

Receipts：每次成功接收的收據。相同檔案重試不會重複記錄。

Record data：完整 JSON 的分段備存。你仍可在教師總覽批次匯入學生的原始檔案，查看逐次實驗。

試算表保持私人，只分享給需要查看的教師。班級代碼是收件門檻，學生代碼由學生自行填寫；它們不等同已驗證的學生身分。收件程式沒有公開讀取全班資料的入口。

只有伺服器完成寫入並返回收據後，學生頁才顯示老師已收到。斷線時先保存在瀏覽器，自動重試最多三次；重新連線、重新開啟或按 Retry 可再嘗試。關閉頁面後不會在背景持續傳送。

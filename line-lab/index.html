Each gene has a chance to change. Some changes help; some do not. Test the next generation to find out.

What this genetic algorithm learns

It searches for PID gain values, not a new set of steering instructions. Genes remain in these ranges: P 2–55, I 0–8, D 0–10. Parent selection uses three-candidate tournaments, crossover chooses each gene from either parent, and mutation changes genes within their ranges. The best two are copied unchanged. All scores and replays come from the same robot simulation as the driving tab.

A high score on one track does not prove that the robot will perform well on another. Apply a robot’s genes in Drive & PID, change the track, and test again. A genetic algorithm can get stuck or plateau.

THE IDEA BEHIND THE ROBOT

A robot follows instructions.
You build the instructions.

An algorithm is a clear set of steps for a task. Here the robot repeats: read the sensors, find the line, choose wheel speeds, and move.

−2−10+1+2

The five sensors sit across the front, from the robot’s left to its right. Darker floor gives a higher reading. We use a weighted average to estimate where the line is. Zero means the line is near the middle; positive means it is on the right.

P
How far off are we now?

P = Kp × error. A larger error asks for a stronger turn.

I
Has an error lasted for a while?

I = Ki × sum(error × cycle time). It can help correct a constant motor imbalance. Too much can make the robot overshoot.

D
How fast is the error changing?

D = Kd × change in error ÷ time. It can reduce wobble by opposing a rapid change. It does not predict the future.

PID is an algorithm too. It adds P + I + D to calculate a steering correction. Start with P, try D, and add I only if a lasting error needs correcting. The full PID is not always the best choice.

Model details & trusted sources

This is a teaching model, not a calibrated copy of a particular robot. It uses differential-drive motion, motor lag, continuous reflectance readings, a fixed 0.02 s control cycle, filtered error change, limited motor commands, and a limited integral accumulator with anti-windup. Positive correction speeds up the left wheel and slows the right wheel.

Old trail sections begin to fade after three quarters of a track-length of travel and disappear by a full track-length. The fresh trail stays visible. When the line is lost, a separate recovery rule turns toward its last seen side. The integral freezes and derivative history resets. After five seconds without the line, the run pauses. A reset clears the run; changing a controller or track starts a new run. Editing gains, speed, or motor weakness marks the test as mixed settings.

The robot now has a faster motor model and independently limited wheel commands, so it keeps steering authority at race pace. Saved tests labelled “earlier model” use the old slower motor model and should not be compared directly. Gain values are specific to this model. Real sensors need calibration and real robots need their own tuning.

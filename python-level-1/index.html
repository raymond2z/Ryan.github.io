Meet your Python editor

Create, save and run your first program.

Python follows the instructions you write. A program usually runs from top to bottom. In this course, use Python 3 and an editor such as IDLE.

Your first saved program in IDLE

  1. Open IDLE. Choose File → New File.
  2. Type the code below in the new editor window.
  3. Choose File → Save and name it hello.py.
  4. Choose Run → Run Module (F5).

LESSON 02

Print, strings & comments

Display text and explain your code.

A string is text inside quotes. Single and double quotes both work when the opening and closing quotes match. A # starts a comment that Python ignores for the rest of that line.

Text, numbers and comments

# This program displays a short message.
print("Hello")
print('Python is fun!')
print(2 + 3)       # Calculate first, then print.
print("2 + 3")     # Print the text exactly as written.
Check the output
Hello
Python is fun!
5
2 + 3

Choose how the output is arranged

print() normally separates its items with spaces and ends with a new line. Use sep and end to change this. Inside a string, \n starts a new line and \t inserts a tab.

New lines and separators

print("red", "green", "blue", sep=" | ")
print("Hello", end=" ")
print("Ada!")
print("First line\nSecond line")
Check the output
red | green | blue
Hello Ada!
First line
Second line

Triple quotes create a multi-line string. They are not a separate comment syntax. Use # for ordinary comments.

LESSON 03

Variables & useful names

Give values names, then update them.

= assigns a value to a name. Python evaluates the right side first, then stores the result under the name on the left. A later assignment replaces the previous value for that name.

A changing score

score = 10
print(score)
score = score + 5
print(score)
print("score")
Check the output
10
15
score
Good namesNames to avoid
score, student_name, side_length2score starts with a digit.
Use letters, digits and underscores; begin with a letter or underscore.my score contains a space; class is a keyword.
Use consistent lowercase names. score and Score are different.print, input, int and str hide useful built-ins.

Python also accepts many Unicode letters in names. We use English names here to keep examples easy to share.

Use values in a message

student_name = "Ada"
age = 10
print(student_name, "is", age, "years old.")
Check the output
Ada is 10 years old.

Convert intentionally

int() converts an integer string to a whole number. float() handles decimal strings. str() converts a value to text. int(3.9) truncates toward zero; it does not round to the nearest integer.

Convert values

print(int("12") + 3)
print(float("12.5") + 0.5)
print("Age: " + str(10))
print(int(3.9))
print(int(-3.9))
Check the output

Age: 10
3
-3

int("3.5") and int("hello") raise ValueError. A string and an integer cannot be joined with + directly. Check the type and choose a suitable conversion.

Make the order clear with parentheses

LESSON 07

Comparisons & logical expressions

Ask questions that produce True or False.

Use == for equality, != for inequality, and <, <=, > or >= for numerical comparisons. A comparison produces a Boolean result. Remember: = assigns; == compares.

Compare two numbers

b = 10

print(a != b)
print(a > b)
print(a < b)
print(a >= 21)
print(b <= 10)
Check the output

True

Combine Boolean conditions

With Boolean conditions, and requires both to be true; or requires at least one to be true; not reverses a truth value. In general Python, and/or can return their operands, so begin by combining explicit comparisons.

Combine conditions

age = 10
height = 135
print(age >= 8 and height >= 120)
print(age < 8 or height < 120)
print(not (age >= 8))
number = 18
print(number % 2 == 0)
print(0 <= number <= 20)
Check the output
True
False
False
True
True

LESSON 08

Turtle: position & movement

Turn instructions into visible paths.

turtle is part of Python’s standard library. It needs a graphical environment with Tk support. Run these examples in a suitable desktop Python editor; they do not draw inside this webpage.

CommandAction
forward(100) / backward(100)Move along the current heading or in the opposite direction.
left(90) / right(90)Turn relative to the current heading.
setheading(90)Face up in standard mode, regardless of the previous heading.
goto(x, y)Move to a position; keep the current heading.
penup() / pendown()Move without drawing / draw while moving.
home()Return to the origin and face right; draws if the pen is down.

Move, then turn

import turtle
turtle.setup(600, 400)
turtle.pensize(3)
turtle.forward(100)
turtle.left(90)
turtle.forward(80)
turtle.hideturtle()
turtle.done()
Preview the drawing

LESSON 09

Turtle: colour, circles & shapes

Control the pen and plan a complete drawing.

pencolor() sets the outline; fillcolor() sets the fill. Put the drawing between begin_fill() and end_fill(). Use pensize() for line width.

circle(radius, extent) draws an arc measured in degrees. A positive radius puts the centre to the turtle’s left; circle(50) uses radius 50, so its diameter is 100. dot(50) draws a dot with diameter 50 at the current position.

A filled circle and a separate dot

import turtle
turtle.pencolor("red")
turtle.fillcolor("gold")
turtle.begin_fill()
turtle.circle(60)
turtle.end_fill()
turtle.penup()
turtle.goto(160, 0)
turtle.dot(40, "blue")
turtle.hideturtle()
turtle.done()
Preview the drawing

A red square with green fill

import turtle
turtle.pensize(3)
turtle.color("red", "green")
turtle.begin_fill()
turtle.forward(120)
turtle.left(90)
turtle.forward(120)
turtle.left(90)
turtle.forward(120)
turtle.left(90)
turtle.forward(120)
turtle.left(90)
turtle.end_fill()
turtle.hideturtle()
turtle.done()
Preview the drawing

Use clear() to remove drawings while keeping the turtle’s state. reset() also resets its position and pen settings. speed(1) is slow, speed(10) is fast, and speed(0) disables animation. Put done() at the end to start the graphics event loop and keep the window responsive until it is closed.

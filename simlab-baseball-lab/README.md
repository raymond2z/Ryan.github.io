# Sim Lab Baseball Lab

An English, picture-led learning resource for upper-primary students creating a baseball game in Tinkercad Sim Lab.

- 36 small steps and 34 English teaching images
- Original KIDSPRO video embedded from YouTube
- Ramp and bat Axis Connector settings, plus an optional Slider Connector launcher
- Local progress, troubleshooting, a word bank, and downloadable student test notes

## Use the website

Open `index.html` in a browser, or host this directory as a static website. No build tools are required. Internet access is required for the video and Tinkercad models. Progress and test notes are stored locally in the browser.

Published in the public `raymond2z/Ryan.github.io` website under `simlab-baseball-lab/`. The portfolio homepage links to this lesson.

## Edit the lesson

Edit `content.json`, then regenerate `content.js` with:

```sh
python scripts/sync_content.py
```

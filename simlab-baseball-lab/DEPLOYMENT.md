# Deployment

This buildless teaching website is published inside the public `raymond2z/Ryan.github.io` repository at `simlab-baseball-lab/`. It uses the repository’s existing GitHub Pages configuration.

The portfolio root `index.html` links to this resource. All lesson files and image assets remain inside this project folder.

To edit the steps, update `content.json` and run `python scripts/sync_content.py` before committing.
